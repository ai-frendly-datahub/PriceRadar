# PriceRadar 데이터 소스 전략

## 리서치 요약 (2025-11-24)

한국 가격 추적/비교 서비스 시장을 조사하여 PriceRadar에 통합 가능한 데이터 소스를 분석했습니다.

## 1. 가격 추적 서비스 (Price Tracking Services)

### 1.1 폴센트 (Fallcent) ⭐⭐⭐
- **URL**: https://fallcent.com/
- **특징**: 쿠팡 전문 가격 추적 서비스
- **제공 데이터**:
  - 역대 최저가 알림
  - 원하는 가격 알림
  - 재입고 알림
  - 핫딜 키워드 알림
  - 가격 변동 그래프
- **장점**:
  - 실시간 가격 변동 추적
  - 14일/30일 최저가 정보
  - 핫딜 큐레이션
- **우선순위**: P0 (최우선)
- **구현 난이도**: 중간
- **데이터 품질**: 높음

### 1.2 역대가 (AllTimePrice) ⭐⭐⭐
- **URL**: https://alltimeprice.com/
- **특징**: 쿠팡 로켓배송 제품 전문
- **제공 데이터**:
  - 가격 변동 추적 그래프
  - 특정 가격 이하 알림 (다중 설정 가능)
  - 가격 히스토리
- **장점**:
  - 기본 기능에 충실
  - 여러 가격대 알림 설정 가능
- **우선순위**: P1
- **구현 난이도**: 중간
- **데이터 품질**: 높음

### 1.3 타이밍 (Timing) ⭐⭐
- **특징**: 쿠팡 가격 추적 + 이미지 제공
- **제공 데이터**:
  - 원하는 가격 알림
  - 상품 이미지 포함 알림
- **장점**: 시각적 정보 제공
- **우선순위**: P2
- **구현 난이도**: 중간

### 1.4 지니알림 (GenieAlert) ⭐⭐
- **URL**: https://geniealert.co.kr/
- **특징**: 쿠팡 가격 변동 추적
- **우선순위**: P2
- **구현 난이도**: 중간

### 1.5 로우차트 (LowChart) ⭐⭐
- **URL**: https://www.lowchart.com/

## 6. 데이터 수집 전략

### 6.1 법적/윤리적 고려사항
- ✅ robots.txt 확인 필수
- ✅ 요청 간격 준수 (최소 1~2초)
- ✅ User-Agent 명시
- ✅ 서비스 약관 검토
- ❌ API 없이 무단 크롤링 주의

### 6.2 기술적 접근 방식

**Tier 1: 웹 스크래핑 (HTML 파싱)**
- 폴센트, 에누리, 다나와 등
- BeautifulSoup/Playwright 활용
- 구조 변경 대응 필요

**Tier 2: API 활용 (공식 API 있는 경우)**
- 현재 공식 API 없음
- 향후 파트너십 가능성

**Tier 3: 데이터 제휴**
- 향후 각 서비스와 데이터 제휴 협의

### 6.3 데이터 품질 관리
- 중복 제거 (상품 URL 기반)
- 가격 정확도 검증
- 수집 실패 로깅
- 주기적 데이터 검증
